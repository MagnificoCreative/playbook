Integration and trust

Once you know who needs what, check whether your data can deliver it. This is where most organizations discover that integration and trust are different things.

If three copies of a number disagree today, putting them side by side on one screen only makes the disagreement easier to see. Trust has to be fixed where the data is born and everywhere it gets changed along the way.

How to apply it

01 / 05
  1. Metrics

    Pick a few critical metrics.

    Start with the handful your leadership relies on most, not every system you own.

  2. Trace

    Trace each one end to end.

    From the system where it’s created to the meeting where it’s used. Note every copy, every change of definition, and every point where a person re-keys or adjusts it.

  3. Retire

    Ask what should have been retired.

    Old dashboards and legacy tools running alongside new ones keep competing versions alive.

  4. Owners

    Name an owner for each definition, even provisionally.

    A number nobody owns will drift again.

  5. Together

    Do it with operations and IT in the same room.

    Neither can see the whole path alone.

One number, many copies

The same patterns appeared in almost all of them. Data was copied between systems and spreadsheets, definitions shifted, figures were reconciled by hand, and new dashboards arrived without the old ones ever leaving.
