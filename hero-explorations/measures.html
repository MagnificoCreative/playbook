Step 4 · Infographic options

From many measures to a few

Six ways to show every measure going through the same five tests. Measures that fail a test are let go right there, and the few that pass all five end up in Safety, Quality, Delivery, Cost and People. Five of the six run top to bottom. The barriers are named as tests, each with a plain question:

1 · Decision: Would anyone act on it? 2 · Shared: Do several roles use it? 3 · Available: Can we measure it today? 4 · Trusted: Is the source reliable? 5 · Important: Does it move the business?

A solid dot is still in. A hollow dot didn't pass. Each option is pinned and scrubbed by scroll.

Option A · Vertical

The sieve

Measures fall from the top. Each dashed line is a test, labelled on the left with its name and question. Measures that fail a test land on that line, turn hollow and roll off the edge. The ones that pass every test drop into the five categories at the bottom. Each line pulses as the measures reach it.

A · The sieve

Option B · Vertical

What each test let go

The same fall, but nothing disappears. Each measure that fails a test slides to a “Let go” column on the right and stays there, lined up next to the test that stopped it. By the end you can see which tests did the most work (the first one catches the most) and how few measures are left at the bottom.

B · What each test let go

Option C · Vertical

The funnel

Each test is narrower than the one above it, so the five lines make a funnel. Measures that fail get pushed out past the edge of their line and fade away, and the stream narrows as it falls. Below the last test, the survivors spread out again into the five categories.

C · The funnel

Option D · Vertical

One test at a time

The tests are introduced one by one, so nobody has to read all five at once. A large caption on the left shows only the test being applied right now: its name and question. Its line darkens while the others stay faint. At the end, the caption changes to sum up what's left.

D · One test at a time

Option E · Vertical

The sheet

This one is calmer and has no physics. The measures sit in a tidy grid that steps down onto each test. The ones that fail stay stuck on that line as a hollow row, and the rest close ranks into a smaller grid and move down to the next test. The few left at the end drop into the categories.

E · The sheet

Option F · Horizontal

Left to right

The current direction, redone. The tests are columns with a clear header (number, name and a two-line question). Measures travel left to right, and those that fail drop to the floor under the test that stopped them, where they pile up. The survivors line up next to the categories on the right.
