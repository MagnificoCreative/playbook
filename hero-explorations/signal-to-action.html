Step 5 · From signal to action

Vertical layouts

The four steps stood on end, top to bottom, with the copy beside them. A and B are the two-column layout you described, with today's dots and with small, delicate dots. C and D try two more ideas. Each one runs as you scroll, the same as on the page: the pink line fills down, and the copy changes as it reaches each step.

A · Rail, current dots B · Rail, delicate dots C · Copy follows the step D · Opens in place

Option A

Rail, current dots

Today's dots and line, turned vertical. The steps run down the left and the copy sits to the right: the headline line, then the example in body copy.

Option B

Rail, delicate dots

The same layout with the lighter language from the other charts: a 1px line and small dots. Steps that have been reached fill pink, and the current one gets a thin pink ring.

Option C

Copy follows the step

Like B, but the copy slides down so it always lines up with the current step. Your eye stays on one line: the step on the left, what it means on the right.

Option D

Opens in place

A single column. The current step opens up underneath its name to show its copy, and the step before it closes. It's the narrowest option, and it would also work on phones without changing.
