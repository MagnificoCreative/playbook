Step 3 · Option A, refined

A copy of a copy

Four quieter takes on option A, each with a trust measure set against it. The number starts crisp at the source with full trust. Every step copies it to the next system, the copy gets a bit worse, and trust drops. There are no figures, only shape, length and fading. Each one plays as you scroll, and backwards when you scroll up.

Option A1

The staircase

The copies sit in an open row with no frames. Under them, a trust line starts at the pink source and steps down once for each copy, in the same language as the intro's “Where trust is lost” chart. A dotted guide drops from each copy to its step, so you read the shape and its trust together.

Option A2

Down the list

Literally going down: one row per step, read top to bottom, like a ledger. Each row has the step's name, its copy of the number, and a trust bar. The rows arrive one at a time as you scroll, each copy a little rougher and each trust bar a little shorter than the one above.

A2 · Down the list

Option A3

Dots and dials

The number is drawn as a row of dots, like data points. Each copy drops a point or two (the hollow gaps), picks up a stray duplicate, and lets the rest drift. Under each copy, a thin dial shows how much of the trust is left. It's full around the pink source and closes a little more with every step.

A3 · Dots and dials

Option A4

One long line

The copies run together as one continuous line, the same shape repeated from system to system, so the decay reads as a single journey. Underneath, a trust band starts wide at the source and tapers as the line travels, ending as a thin sliver at the dashboard.
